# MemoBox（墨盒）UI 设计提示词

请基于以下产品需求，设计一款 **纯本地、轻量级、无需联网的 PC 端个人笔记管理与信息速记桌面应用** 的高保真 UI 设计稿。

---

## 一、产品背景

产品名称：**墨盒（MemoBox）**

MemoBox 是一款面向个人用户的本地笔记与信息速记工具，核心价值是：

* 打开即记
* 粘贴即存
* 自动保存
* 快速搜索
* 本地可控
* 便于导出

它不是云笔记，不需要登录，也不依赖网络。
它主要用于管理个人零散信息，如：

* 临时文本
* 代码片段
* 操作记录
* 网页摘录
* 账号说明
* 截图图片
* 各类 Markdown 笔记

### 产品核心特点

* 纯本地运行，无需联网
* 首发平台为 **macOS**，同时需要兼容 **Windows**
* 编辑器采用 **纯 Markdown 源码模式**
* 支持 **笔记管理、分类管理、标签管理**
* 支持粘贴 **纯文本**
* 支持粘贴图片，并按 **原图片格式** 本地保存
* 支持 **自动保存**
* 支持 **撤销 / 重做**
* 支持 **全局搜索**
* 支持 **导出 Markdown**
* 支持 **回收站**
* 分类最多支持 **5 级嵌套**

### 目标用户

* 开发者
* 办公人员
* 内容创作者
* 重度剪贴板用户
* 注重隐私的个人用户

### 设计目标

请设计一套适合桌面效率工具的 UI，强调以下感受：

* 安静
* 克制
* 专业
* 轻量
* 易读
* 高效率
* 本地优先
* 信息密度适中，不花哨

## 二、页面清单

请输出以下页面 / 界面设计，保持统一的设计语言，并优先采用 **桌面端三栏布局**。

### 1. 主工作台 / 笔记主页

采用三栏结构：

* **左侧导航栏**

    * 全部笔记
    * 最近编辑
    * 分类树
    * 标签入口
    * 回收站
    * 设置

* **中间笔记列表区**

    * 当前分类 / 标签 / 搜索条件标题
    * 新建笔记按钮
    * 搜索框
    * 筛选与排序入口
    * 笔记列表项（标题、摘要、更新时间、标签、置顶状态）

* **右侧编辑区**

    * 笔记标题输入区
    * 分类选择器
    * 标签选择器
    * Markdown 源码编辑器
    * 自动保存状态
    * 导出按钮
    * 删除按钮
    * 更多操作入口

### 2. 新建笔记 / 空状态界面

需要展示在以下场景中的空状态设计：

* 首次进入应用，无任何笔记
* 当前分类下无笔记
* 当前标签下无笔记
* 搜索无结果
* 回收站为空

空状态需要简洁、友好，并引导用户执行下一步操作。

### 3. 分类管理界面 / 弹窗

用于管理最多 5 级分类，需支持：

* 新建分类
* 新建子分类
* 重命名分类
* 拖拽排序
* 拖拽调整父子层级
* 删除分类
* 删除时展示两种处理方式：

    * 仅删除当前分类
    * 删除整个分类分支

请重点表现树状结构、层级关系和操作可理解性。

### 4. 标签管理界面 / 弹窗

用于：

* 创建标签
* 重命名标签
* 删除标签
* 搜索标签
* 查看标签关联笔记数量

请体现标签的轻量管理体验。

### 5. 全局搜索结果界面

设计全局搜索状态：

* 搜索输入框
* 搜索结果列表
* 每条结果显示：

    * 标题
    * 摘要
    * 所属分类
    * 标签
    * 更新时间

注意：

* 搜索结果只需要帮助用户找到“所属的笔记”
* **不需要高亮关键字**
* 不需要设计正文精准定位样式

### 6. 导出弹窗 / 导出进度界面

用于导出：

* 单条笔记
* 某个分类下的笔记
* 某个分类及全部子分类下的笔记
* 某个标签下的笔记

需要设计：

* 导出范围选择
* 导出目录选择
* 是否包含子分类
* 导出进度
* 导出成功提示
* 导出失败提示

请体现“导出目录根目录统一 assets 文件夹”的设计说明。

### 7. 回收站界面

用于展示已删除笔记，支持：

* 恢复笔记
* 永久删除单条笔记
* 清空回收站

需要明确区分“普通删除”和“永久删除”的视觉层级，减少误操作。

### 8. 设置页面

设置项包括：

* 查看当前数据目录
* 打开数据目录
* 默认导出目录
* 笔记默认排序方式
* 主题设置（浅色 / 深色 / 跟随系统）
* 编辑器字体大小
* 是否显示分类笔记数量
* 应用版本
* 本地数据结构版本

注意：

* **不要设计“修改数据目录”功能**
* **不要设计备份与恢复功能**

### 9. 异常 / 提示状态

请补充以下通用状态设计：

* 自动保存中
* 已保存
* 保存失败
* 图片格式不支持
* 图片保存失败
* 磁盘空间不足
* 删除确认弹窗
* 永久删除确认弹窗
* 导出完成提示
* 轻量 Toast / 通知提示

## 三、设计系统

### 1. 整体风格要求

整体视觉风格请参考 **Claude Code 官方文档** 的色调气质，重点参考其：

* 安静克制的中性色体系
* 温和偏暖的背景色
* 清晰但不过分强烈的对比
* 低饱和、专业感、工程感
* 简洁的层次和舒适的阅读体验

请不要做成过度炫技或营销感很强的风格，而应更像一个高质量、现代化、可信赖的桌面效率工具。

### 2. 推荐配色方向

请使用接近 Claude Code 官方文档气质的配色体系，建议如下：

#### 浅色主题主色板

* 主背景：暖白色 / 米白色，例如 `#F7F5EF`
* 次级背景：更浅的暖白，例如 `#FBFAF6`
* 卡片背景：柔和浅米色，例如 `#F1EDE3`
* 主文字：深石墨色，例如 `#1F1D18`
* 次文字：中性灰褐色，例如 `#5E5A52`
* 边框色：柔和浅灰褐，例如 `#DED8CC`
* 分割线：低对比暖灰，例如 `#E7E1D7`

#### 强调色

请使用 **低饱和暖橙 / 琥珀橙** 作为主强调色，接近 Claude Code 官方文档的强调感，例如：

* 主强调色：`#D97757`
* Hover：`#C96A49`
* Active：`#B95B3B`

#### 功能状态色

* 成功：低饱和绿色，例如 `#4D7C61`
* 警告：柔和金棕色，例如 `#B8892D`
* 错误：克制的红棕色，例如 `#C65D5D`
* 信息：中性蓝灰色，例如 `#5B7A95`

### 3. 深色主题

请额外给出关键页面的深色模式设计稿，整体仍延续 Claude Code 官方文档风格，避免纯黑，采用：

* 深灰褐 / 深石墨背景
* 柔和暖色文本
* 低饱和强调橙色
* 保持良好阅读对比度

### 4. 字体与排版

请使用适合桌面效率产品的排版体系：

* 中文界面字体：现代、清晰、可读性高
* 英文与代码字体：适合 Markdown 源码编辑器的等宽字体
* 标题、正文、辅助信息要有明确层级
* 正文区重视长时间阅读与编辑舒适度

建议层级：

* 页面主标题
* 区块标题
* 列表主信息
* 次级描述
* 辅助状态文本
* 代码 / Markdown 正文

### 5. 圆角、阴影与边框

整体风格应克制、精致：

* 圆角：中小圆角，建议 8px ~ 12px
* 卡片与面板以弱边框为主，阴影非常轻
* 避免厚重投影
* 利用背景层级、描边和留白来建立结构

### 6. 间距系统

请建立统一的桌面端间距系统，例如：

* 4 / 8 / 12 / 16 / 20 / 24 / 32
* 三栏布局需要有明确节奏感
* 列表、表单、弹窗、编辑器内部间距需统一

## 六、交互与体验要求

请在设计稿中体现以下交互逻辑：

1. **自动保存是核心体验**

    * 用户编辑后无需手动保存
    * 需要在界面上清晰感知保存状态

2. **搜索强调“找到笔记”**

    * 搜索结果清晰、直接
    * 不需要高亮关键字
    * 不要做复杂搜索分析界面

3. **Markdown 编辑体验要清晰**

    * 代码字体清晰
    * 光标、选区、行间距舒适
    * 支持长文本编辑场景
    * 明显体现它是“源码模式”，不是富文本编辑器

4. **分类树要易管理**

    * 最多 5 级
    * 清晰体现层级结构
    * 删除与移动时要避免误解

5. **桌面效率感**

    * 操作密度适中
    * 信息层级明确
    * 减少视觉噪音
    * 适合长时间使用
